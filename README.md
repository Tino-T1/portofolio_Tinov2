# Futuristic Portfolio 2026

A premium, modern developer portfolio built with vanilla HTML, CSS, and JavaScript.

## Features
- **Magic UI Aesthetics**: Glowing effects, glassmorphism, and neon accents.
- **Futuristic Animations**: Smooth scroll reveal, typing effect, and custom cursor.
- **Responsive Design**: Fully optimized for Mobile, Tablet, and Desktop.
- **Vanilla Tech**: No frameworks, no build tools, just clean code.
- **GitHub Pages Ready**: Optimized for static hosting with relative paths.

## Structure
- `index.html`: Main structure and SEO meta tags.
- `style.css`: Design system and animations.
- `script.js`: Interactivity and logic.
- `assets/`: Images, icons, and certificates.

## Deployment
1. Upload all files to your GitHub repository.
2. Go to Repository Settings -> Pages.
3. Select the `main` branch and `/root` folder.
4. Your site will be live at `https://your-username.github.io/repo-name`.
